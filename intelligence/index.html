      Control monitor

      This page asks the data source whether it may show data, by itself, while the tab is visible. When the answer is anything but a fresh, valid “on”, the data is removed from the page and no data request is made. Nothing here is fetched while the tab is hidden.

      What is here, what is planned, what this data cannot show

      Available now

      • Map with selectable nodes and connections, four map windows
      • Globe: the same selection, loss colours and filters on a sphere you can turn by dragging, with the keyboard or with buttons
      • Latency matrix: one cell per pair, one published direction each, with a loss lens
      • Round-trip time against distance, with the physical floor drawn apart from the measurements
      • Packet loss list with the 95% interval for each pair
      • Filters for node, country, round-trip time, packet loss and text; the legend entries filter too
      • Sortable pair table, details, provenance, derived values labelled
      • Freshness states, switched-off and error states
      • Automatic control re-checks, a bounded lease, data removed (not hidden) when closed, re-opening only after repeated fresh confirmation
      • Shareable links: the address after the # holds the view, never the search text you type; Copy link, Reset view

      Not built yet

      • Both directions of each pair, collection method details

      Not available from this data

      • Time range, history or trends: each pair is one 36-minute window
      • Jitter, percentiles, routes, hops, networks
      • Live or streaming values
